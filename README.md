# Bitva mozků

Mozková kůra bojuje proti plazímu mozku. Každému z nich pomáhá malý dopamín,
jeden hodný a jeden zlý. Kdo má hodného dopamína, bije silněji.

Když na kteréhokoli bojovníka klikneš (ťukneš), mozková kůra se promění na plazí mozek,
plazí mozek na mozkovou kůru a dopamíni se taky promění:
hodný se stane zlým a zlý hodným.

Spuštění: otevři soubor `index.html` v prohlížeči.
