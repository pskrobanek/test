# Bitva mozků

Mozková kůra bojuje proti plazímu mozku. Každému z nich pomáhá malý dopamín,
jeden hodný a jeden zlý.

- **BOOST** vedle každého mozku mu přidá 10 životů.
- **FIGHT!** uprostřed spustí souboj. Vyhraje ten, kdo má víc životů,
  a ten, kdo prohraje, se vypaří. Při stejném počtu životů je remíza
  a vypaří se oba. Tlačítkem **ZNOVU** se hraje další kolo.
- Když ťukneš na bojovníka, mozková kůra se promění na plazí mozek a naopak
  (i se svými životy) a dopamíni se taky promění: hodný se stane zlým a zlý hodným.

Spuštění: otevři soubor `index.html` v prohlížeči.
